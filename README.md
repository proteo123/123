# Make.com + Telegram: загрузка 2 фото и анализ OpenAI

Ниже — пример сценария в Make.com для Telegram‑бота, где пользователь отправляет **две фотографии** и **рост**, а система анализирует изображения с помощью OpenAI. Если пользователь отправил только одно фото, бот просит дослать второе. Результат анализа возвращается в Telegram.

## 1) Что понадобится

- Telegram Bot (через BotFather).
- Сценарий Make.com.
- Модуль OpenAI (Vision).
- Хранилище состояния (Data Store в Make.com), чтобы помнить, сколько фото прислал пользователь.

## 2) Логика сценария

**Идея**: каждый пользователь имеет запись состояния (по `chat_id`), где мы храним:
- `photos` — список file_id (или URL) уже полученных фото.
- `height` — рост пользователя.

Когда приходят новые сообщения:
1. Если это **фото**, добавляем к `photos`.
2. Если это **текст** и содержит рост — сохраняем `height`.
3. Как только есть **2 фото + рост**, запускаем OpenAI Vision и возвращаем результат.
4. Если чего‑то не хватает — просим пользователя дослать (например, «Пожалуйста, пришлите второе фото» или «Укажите рост»).

## 3) Пример сценария (Make.com)

### Модули

1. **Telegram Bot → Watch updates**
   - Тип обновлений: Messages.

2. **Router** с ветками:
   - Ветка A: сообщение содержит `photo`.
   - Ветка B: сообщение содержит `text`.

3. **Data Store → Get a record**
   - Key = `chat_id`.

4. **Data Store → Create/Update a record**
   - Храним структуру:
     ```json
     {
       "photos": ["file_id_1", "file_id_2"],
       "height": "180"
     }
     ```

5. **Telegram Bot → Get a file** (для каждого фото)
   - Конвертируем `file_id` в URL, если нужно отправлять в OpenAI.

6. **OpenAI → Create a response / Vision**
   - В запросе указываем две картинки + текст с ростом.

7. **Telegram Bot → Send a message**
   - Возвращаем результат пользователю.

### Ветка A: пришло фото

1. Получили `photo` → сохраняем `file_id` (берем самое большое разрешение).
2. Загружаем текущее состояние пользователя (Data Store → Get a record).
3. Добавляем новый `file_id` в массив `photos`.
4. Сохраняем состояние.
5. Проверяем:
   - Если `photos.length < 2` → отправляем сообщение: **«Пожалуйста, пришлите ещё одно фото.»**
   - Если `photos.length >= 2` и есть `height` → переходим к анализу.
   - Если `height` нет → просим рост.

### Ветка B: пришел текст

1. Извлекаем рост (например, регуляркой `\b(1[5-9]\d|20\d)\b`).
2. Сохраняем `height` в Data Store.
3. Проверяем:
   - Если `photos.length < 2` → отправляем: **«Спасибо! Теперь пришлите два фото.»**
   - Если `photos.length >= 2` → анализ.

## 4) Пример запроса в OpenAI (Vision)

В поле prompt:
```
Проанализируй две фотографии пользователя. Рост: {{height}} см.
Дай краткий анализ и рекомендации.
```

В качестве изображений — два URL файла, полученных из Telegram.

## 5) Очистка состояния

После успешного анализа:
- Обновить Data Store → очистить `photos` и `height`.

## 6) Ответ пользователю

Отправить результат анализа из OpenAI обратно в Telegram сообщением.
